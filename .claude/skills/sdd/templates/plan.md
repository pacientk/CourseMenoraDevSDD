## 7. Гейты

Перед записью каждой строки проверено, что инструмент существует. Чего нет —
`aspirational — not wired`.

| Гейт | Когда | Чем | Подключён |
|---|---|---|---|
| G4 Task DoD | после каждой задачи | `npm run validate` + hand-off | {да} |
| G5 Review | после последней волны | `/reviewer:review` → `/sdd fix`, до 2 раундов | {да / aspirational — not wired} |
| G6 Security | после `APPROVED` | `/security-review`, `npm run audit:deps` | {да / aspirational — not wired} |
| G7 Spec close | после security | `/sdd close` | да |
| G8 Build | в `/sdd close` | `npm run release:check` | да |
| G9 Release | в конце | `npm run preview` + ручная проверка | да |
