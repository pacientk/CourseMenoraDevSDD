# Release notes

## 2026-11-09 · SPEC-002 · Профиль клиента 360

- Страница `/customers/:id` показывает две независимые карточки: данные клиента и его задачи.
- У каждой карточки есть состояния загрузки, «не найдено» и ошибки с кнопкой «נסו שוב». Сбой одной карточки не ломает другую.
- Показываются только поля из белого списка; чувствительные данные API (`password`, `ssn`, `bank`) на странице не выводятся.
